# projectplanner
One-page, drag &amp; drop project plan (EN/TR). Node.js, no dependencies.

**Live demo:** https://yildreams.github.io/projectplanner/ — the demo has no server, so plans are saved in your browser only.

## Run locally
```
npm start        # http://localhost:3000, plan is saved to data/plan.json
```

## Export
- **Excel (.xlsx)** – plan sheet with day-accurate date lines, plus a sortable/filterable details sheet.
- **PNG image** – high-resolution picture of the plan, or copy it straight to the clipboard.
- **Print** – browser print / save as PDF.
